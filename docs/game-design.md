# リアルフェイクタウン（仮） 企画書 v0.3

> 盲目のお爺さんが点字ブロック（視覚障害者誘導ブロック）の文法の上を自律的に歩く。
> プレイヤーはクセだらけの「親切ピース」を静かな街に配置し、優先度と幾何を読んで、
> 親切の連鎖でお爺さんを駅まで届ける —— PLATEAUの実在の街を盤面にする、決定論ターン性誘導パズル。
>
> **動くのはお爺さんだけ。街は、親切で満ちた静止画。**

> v0.3（2026-09-27）: 時刻・タイマー・動くピースを全廃止し、完全離散の最小コアに再構成した。
> v0.2 から外した案はすべて §20「後回し棚」に記録。決定の現在状態は §17 決定ログが正。

## 1. 参照作品から汲むもの

| 作品 | 採用する要素 |
|---|---|
| 『影牢』 | 対象の来る経路を**読んで仕込む**楽しさ。トラップ（親切）コンボの設計（実時間で置く緊張感は v0.3 で手放した） |
| 『チューチューロケット』 | **決定論的**な移動、いつでも設置できる手数、複数の動体の干渉を読むパズル性（実時間性は無料巻き戻しに置換） |
| 『Traffic Escape』 | 俯瞰視点で**道路が常に読める**レイアウト（建物を少し斜めに配置して道を隠さない） |

差別化の核：**点字ブロックの現実の文法（直線＝進め／点＝判断／警告＝止まれ）をそのままパズル言語にする**こと。
遊ぶほど実在の街の読み方が上達する＝「いつもの街で人に親切になれる」テーマの裏付け。

## 2. ゲームの骨格（v0.3 確定）

- **ターン性 × 完全決定論**: 盤面は完全に静的。**お爺さんが唯一の動体**で、人も物も設備も置かれたまま動かない。1ステップ＝1ノード移動。時刻・秒・同時進行といった「時間の概念」はルールに存在しない（D39）。
- 設置は**いつでも可能**。**巻き戻しはいつでも・何手でも無料**（完全決定論なので再現にコストがなく、実時間はルールに影響しない）。実時間は「歩きを見る演出」である。
- **勝利**: 駅前の駅員さんに到達。
- **敗北**: **歩数0 → 即リトライ**（試行コストを最小化し、パズルの反復を促す）。
- **歩数**: 1ノード移動＝1消費、停止（指示待ち・立ち寄り・立ち話）＝2消費。コンビニで全回復（**回復は各1回限り**・D25）。
- **スコア**: 親切連鎖（§6）＋残り歩数で星評価（§9）。

### 1ステージの流れ

1. **観察**: 街は静止画なので**完全情報**——すべてのピース・矢印・閉鎖が最初から読める。
2. **配置と実行**: 歩きを見ながら置き替えても、巻き戻して計画し直してもよい。
3. **結果**: クリアで星評価＋お爺さんのお礼イベント。失敗は即リトライ。
4. **ふりかえり**: リザルトに「今日出会えた人」が並ぶ。

- 星2の「ノー巻き戻し」だけが実時間プレイ（通しで解く挑戦条件）になる。

## 3. お爺さんの移動ルール（パズルの言語）

点字ブロック網 = グラフ。**直線ブロック＝辺、方向ブロック（点）＝判断ノード、警告ブロック＝停止ノード**。

**ジジイの行動ルール（v5・発火順のみ）**——方向の決定はこの1本の優先度で完結する（v0.2の「判断順」レイヤーは土地勘の廃止とともに統合した・D31改訂）。

1. **人の声**（善し悪しを問わない——**爺は人の声を疑わない**）: 人のピースがある角では必ず呼び止まって従う。**嘘つきも「人」である**（矢印の逆を指す、本気の親切者）。
2. **点字**: 点字つき交差点では、駅方向矢印どおりに自分で進む。**置き自転車と嘘つきは点字を隠す**（隠された場所では発動しない）。
3. **ハチの強制**: 「必ず右」（クセ。§4 参照）。
4. **デフォルト**: 一方しか進めなければそれへ（行き止まりでは戻る）／直進できるなら直進／**T字で行き先に困ったら法律どおり右**（D29）／広場（警告ノード）と開始直後は停止・指示待ち（D18）／完全に閉ざされたらゲームオーバー。

**その他の確定ルール**:

- **出口が一箇所でも封鎖されていれば、封鎖された出口は選択肢から除外され、空いている方へそのまま進む**。
- **1マス1イベント**: 交差点に世界のイベントを重ねて置かない——生成器の硬い制約。人のピースによる呼び止め（最上位）は常に可能。
- **同段位の指示が競合 → 最も近い発信源が勝つ → さらに同距離なら右回り**。UIで可視化する（影響範囲と優先順位の表示）。
- **嘘つきお兄さん**: 必ず「**駅から遠ざかる方向**」を指示（距離増加が同じなら右回り）。**このルールは本作のキモとして不変**。点字を隠し、爺は無条件で従う。カウンタは2つ: ①その角に人のピース（お巡りさんを含む）を置けば無効化 ②**一度騙されると二度と聞かない**（再会表: [1回目: 従う → 2回目以降: 無視]）。
- **歩数**: グラフを通過するたびに必ず消耗する（移動1・停止2——一方通行で入れないT字での足止めも同様）。**0で帰宅**。累積回復量が有限（回復は各1回限り）なので、シミュとソルバの探索は必ず停止する。
- ワープ・移動効果は存在しない（お爺さんを運ぶピースはv1にない。後回し棚 §20 参照）。
- 通過中の方向転換は存在しない。枝入口を作りたい盤面は直進を断つか警告ノードに格上げして停止を作る。

**盤面は歩行パス網**: 道の中央に点字ブロック網が敷かれ、**そこだけが歩ける**。車・センターライン・横断歩道の白線・信号機といった車道の情報は、パズルに不要なので**盤面から消す**（D16）。お助けキャラは道の脇（路肩）に立って声をかける。

- **「横断歩道がないので通れない」は事故メタファーで語る**: 衝突判定などの危険処理は存在しない。「事故があるから、ここにはブロックがない」と物語で説明する。壁の正体は情報の欠落。
- **閉鎖は2段階**: **ギャップ**（横断歩道なし・事故メタファー・迂回のみ）→ **工事中**（物理的な通行止め。実在の工事）。**盤面の縁は仮囲いが自動で巡る「整備中の区画」**としてコースアウトを防ぐ（お爺ちゃんは律儀なので柵を守る）。（弱い工事＋担送は後回し棚へ）
- **一方通行**: 実在の一方通行は盤面にも反映する（矢印の向きにだけ歩ける）。行き止まり（出口のないノード）に足を踏み入れると身動きが取れず、**その場で帰宅＝ゲームオーバー**（D25）。

## 4. 「クセ」の設計記法（全ピース共通仕様）

**クセ ＝ 本業とは別に必ず発動する、決定論的な奇妙ルール。**
「条件 → 動作 → フォールバック」の連鎖で仕様化する。実装は小さなルールテーブル、テストは決定論、
プレイヤーには「あの犬は右を塞いで使えば左になる」といった読み合いが生まれる。

**見本（変更不可の正式仕様）**:

```
[わがまま誘導犬ハチ]（介護犬仕様）
本業 : 駅方向矢印どおり、お爺さんと一緒に歩く（1区間エスコート）
クセ : 次の交差点で必ず「右折」を指示してエスコート完了。
       右に曲がれるブロックがなければ左折、それもなければ任務終了——
       お爺さんを置いてダッシュで走り去っていく（仕事終わりは公園へ）。
抵抗 : なし。読むのは幾何——右を塞げば左、それもなければ任務終了。
       強制イベントへの対抗はつねに盤面の幾何で行う（D26廃止）。
```

**設計原則**: クセは「欠陥」ではなく「仕様」。すべてのクセはゲーム内のピース図鑑に記載し、
導入ステージで1つずつ単独紹介してから、組み合わせパズルへ進む（フェアネスの担保）。

**納得感の型（全ピースが通す4テスト）**: クセは「欠点」でも「仕様」でもなく、**その人の生活の痕跡**として書く。

1. **写真テスト**: 実在の街の写真に紛れる人・物か（架空の職業・存在を持ち込まない）
2. **動機テスト**: クセは本人の生活・目的から自然に流れているか（プレイヤーのために動かない）
3. **セリフテスト**: 口にする一言でルールが説明できるか（チュートリアルの代わりになる）
4. **居場所テスト**: そこに**いる**ことがその人の生活として語れるか（いつ現れるかではなく、なぜそこにいるか）

**ありがた迷惑ラベル**: 痕跡が盤面にぶつかったものがありがた迷惑である。**副作用はすべて逆利用が1行で書けなければならない**——書けない副作用は理不尽であり、リジェクトする。図鑑は「本業／クセ／ありがた迷惑の顔／逆利用／カウンタ」の5項で書く（D21の技術点採点と接続）。

**再会スクリプト（触発型の一般形）**: 触発され得るピースは**再会回数ごとの挙動表**を持つ（最小形: 嘘つき=[1回目: 従う → 2回目以降: 無視]）。すべて決定論で、図鑑に明記し、導入ステージで単独紹介する（初見死ゼロ）。

**シンプルさの原則（キャラの効果の上限）**: 各キャラの効果は、①お爺さんへの直接効果、②小さな範囲（隣接〜1ノード）、③単一機能、に限定する。

- **騒ぐ**ことが主軸のキャラ（広範囲の掛け声・鳴き声など）を作らない
- **空間的な範囲効果**（オーラ・視界バフ・エリア強化）を持たせない
- **他のキャラへの干渉**（黙らせる・強化する・開ける）を持たない。ピース同士の連携は、特殊能力ではなく**プレイヤーの配置（幾何）だけ**で生まれる

## 5. ピース一覧（v1・11種）

新しいキャラは4条件をすべて満たせば採用する。

1. **現実から拾う**: 街に実在する人・設備から候補を出す
2. **本業1つ＋クセ1つ**: §4のクセ記法で1行に書けること
3. **カウンタを必ず1つ**: 幾何（配置・盤面）で無効化できること
4. **逆利用が1行で書ける**: 「そのクセをこう使えば強い」が書けなければリジェクト

機能は8系統でカバーする: **誘導①／声かけ②／停止／回復／情報／阻害（壁）／逆誘導／自律（理性発揮）**（音③は空席・§20）。

**操作分類は2種のみ（D20改訂）**: **持ち駒**（プレイヤーが配置する）と**環境**（街に最初からある・固定）。中立キャラ（自分の用事で動くキャラ）は廃止した。

### 個別仕様メモ

- **おばちゃん**: 「待ち」は時間でなく1手。停まった1手の対価として情報が漏れる——**確実な指示と引き換えの歩数調整器**。逆利用: 停止を作りたい角に置く。
- **お巡りさん**: 最上位だが方向指定不可——**駅方向が都合よくなる地点**を盤面から読んで置く。嘘つきの無効化は「付き添い」ではなく**配置カウンタ**（同じ角に置くだけ）。
- **ハチ**: 抵抗手段は存在しない。右を塞ぐ・左を受け止める・任務終了を読む——すべて幾何の読み。
- **嘘つき**: 可視性——配置時点で「駅方向矢印の逆」が確定し、彼が指差す方向が常時表示される（D23）。1回騙されると以後無視するので、繰り返し騙される理不尽はない。
- **警備員**: 「立ちはだかる親切」。開けるには立ち話という**歩数を払う**。誤方向への進入防止（ハチの強制右の受け止めなど）が主用途。
- **置き自転車**: 二用途——①街に置かれている分は**選択を迫る障害**（移動させるか、人の案内に切替えるか）②手持ちで設置すると**自律を潰して別の案内に差し替える**テクニカル技。

### 導入カリキュラム（ステージ解放順）

1. まっすぐ道を渡って（女子高生のみ。誘導レーンと点字ブロックの文法を覚える）
2. おまわりさんのいる交差点（方向指定できないピースとの付き合い方）
3. ハチの右（クセのフォールバックを幾何で読む）
4. 嘘つきの近道（逆誘導の活用と無効化）
5. 道が途切れる場所（事故メタファー。ギャップと迂回を覚える）
6. 歩数のない日（歩数・コンビニの回復）
7. 立ちはだかる親切（警備員さん。点字をつぶす置き自転車）
8. 親切の連鎖（コンボの幾何・自由編成の解禁）

## 6. 親切コンボの定義（幾何連鎖）

- 親切（ピースの発動）が**盤面の幾何でつながって決まる**ほど連鎖が伸びる: 親切イベント同士を**Nノード以内**でつなげて発動させると「親切×3連鎖！」（Nはステージ設定）。
- 連鎖を作るのは**配置の幾何だけ**（時間ではない）。
- 連鎖の報酬: スコア加算のみ（v0.3で返金は外した・§20）。連鎖はリズム演出（§14のハーモニー）と星評価の材料になる。
- 影牢のトラップコンボの親切版（実時間でなく幾何でつなぐ）。

## 7. 配置システム（ゲーミフィケーションの核）

### 親切ポイント（KP）— 配置の通貨

- ステージ開始時にKP支給（ステージごとに固定）。ピースごとに設置コスト（§5表のとおり）。
- **返金・コンボボーナスなし**（v0.3）。予算は最初から最後まで固定——計画は配置の幾何だけで完結する。
- 差し渡し: 未使用KPはスコア（残親切ボーナス）に加算。
- リポジッシュ: 声かけ系は撤去・再配置自由（KP移動のみ）。誘導①系（ハチ）は1回限り。

### 配置ルール（パズルとしての制約）

- **置ける場所**: 原則「歩道上」（お爺さんと同じ目線）。車道・工事中・私道は置けない。
- **アンカースロット**: 交差点の四隅・店の前など、実在の「人が立つ場所」は専用スロットになり、**効果+25%**。
- **向き指定**: 声かけ系は向きを持つ（道のどちら側で、どちらを向いて立つか）。
- **駅方向矢印（D23）**: 交差点の判断点には「駅への最短方向」が歩道に描いてある（実在の駅前案内表示が原型）。点字つき交差点・お巡りさんはこの矢印どおりに案内し、**嘘つきは矢印の逆**を指す——方向に関わる全要素が盤面から読める。
- **宣言型方向（D23）**: 方向を持つピースは配置した時点で矢印が確定・表示される。解くまで方向が不明な仕様は禁止（§16 初見死ゼロ）。
- **プレビュー**: 設置前に①効果圏 ②優先度ラダーの重なり ③お爺さんの予測経路ゴースト、を表示。「読み」を「賭け」にしない情報公開が本作のフェアネス。
- **巻き戻し**: いつでも何手でも無料。星2の「ノー巻き戻し」だけが挑戦条件。
- **ステージアーキタイプ**: **v1は「自由配置」のみ**（いつでも・どこでも・歩道上）。固定キャスト（B）・石の街（C）・ミューテーター（D）は後回し棚へ（§20）。

## 8. 固定キャスト（後回し棚へ移設）

狛犬・バス停のベンチ・ラジオ体操クラブ・郵便屋・交差点の誘導員は、v0.3 で**後回し棚（§20）へ移設**した。
回復はコンビニ1種に集約し、「動けないことがクセに昇格する」キャラ群は、アーキタイプ（固定キャスト・石の街）と一緒に再設計して戻す。

## 9. スコア・星（1ステージ3星）

- **星1**: クリア。**星2**: 規定歩数以内。**星3**: ノー巻き戻し（実時間での通し挑戦）。
- **お礼の一言**: お爺さんは親切を受けるたびにその人への一言を残す（リザルトの「今日出会えた人」に並ぶ）。
- お礼コレクション・図鑑収集・称号・街実績・デイリー・リプレイ共有は**後回し棚**（§20）。収集を気にしないプレイヤーを排除しない方針は不変。

## 10. ステージ ＝ 街（PLATEAUパイプライン）

1. **インポート**: PLATEAU SDK で対象範囲（数メッシュ）を取り込む。Building / Road / Bridge / Rail。
2. **歩道抽出**: 道路モデルの車道・歩道（幅員情報つき）から歩行者ネットワークを生成。整備差のある都市向けに「道路ポリゴン端をオフセットした疑似歩道」をフォールバック実装。
3. **誘導レーンの自動生成**: **道路中央**に直線ブロック（誘導レーン）、角に方向ブロック、ギャップ・工事中・改札の手前に警告ブロック。**横断歩道のない交差点はレーンを敷かない（事故メタファーで語るギャップ、§3）**。工事中は実在の工事情報がある場所だけに配置する。盤面の縁は仮囲いで自動的に閉じる。点字ブロックの実データは存在しないため**自動生成＋手編集が正式仕様**。
4. **ブロック網エディタ**（Unityツール）: ペイントで編集・開拓。ステージ設計の主作業場。
5. **開始/ゴール指定**: 駅は駅データ or 手指定。開始点は公園・自宅など。
6. **ピース予算と使用可能ピース**をステージごとに指定。
7. **ソルバQA**: 完全離散の決定論シミュなので、幅優先探索で「予算内に解けるか」を自動検証できる（エディタ機能）。時刻・秒の状態変数が存在しないため、探索空間は位置×歩数×ピース状態の積のみ。

## 11. デフォルメと可読性の線引

> ビジュアルモックアップ: [docs/concepts/map-mockup.png](concepts/map-mockup.png)（`tools/gen_map_mockup.py` で生成）

- **削る**: メカニクスに参加しないものすべて（細街路、駐車場、小物、看板、内装）。
- **残す/誇張**: 誘導レーン（中央のブロック網）、工事中の橙白バリケード、**事故多発地点の黄色い斜線とダイヤ標識**、ランドマーク（交番・駅・コンビニ）、建物のシルエット。信号機・センターライン・横断歩道の白線など車道の情報は描かない。
- **建物**: フットプリントは元データのまま保持し、中心ピボットで ±10〜15° 交互に回転（俯瞰で道路を隠さない。接触判定は元フットプリント）。高さは5段階に量子化。トゥーン＋輪郭線。パレット6〜8色。
- **ランドマーク**: 各エッジ／交差点の代表建物1棟のファサードを Unity 正射影カメラでトゥーン焼きしたカードを配置する（D33。選定ルール・フォールバックは docs/board-generation.md）。
- **カメラ**: 方位固定の高俯瞰。回転は90°ステップのみ（方位感覚を壊さない）。近接建物は半透明化。

## 12. トーンとテーマ

- お爺さんは「可哀想な人」ではなく**マイペースな主人公**。お礼イベント（褒め）が連鎖の演出になる。
- 点字ブロックの文法がそのままルール → 遊ぶほど実在の街の読み方が上達する。
- 一言テーマ: **「親切は、つながる」**。副題: **ありがた迷惑も、親切のうち**——副作用も含めて全部パズルになる（§4 ありがた迷惑ラベル）。

## 13. 画面とモード一覧（v1）

- **タイトル**
- **ステージ選択**: 街全体が1枚の盤面絵で並ぶ（点字ブロック網がそのまま導線になる）
- **プレイ**: 盤面＋HUD（親切コンボ・歩数・残りKP・ピーストレイ）
- **リザルト**: 星評価・連鎖数・「今日出会えた人」・お爺さんからの一言
- **ピース図鑑**: §4・§5のクセ仕様書がそのまま閲覧できる

## 14. アート・サウンド方針

- トゥーン＋輪郭線、パレット6〜8色。建物は単純形状にデフォルメし、**変形ランドマーク**（喫茶ライオン、ドーナツやさん、まがりビル等）にのみ記憶点を与える
- キャラは円形シルエットのちびキャラ。俯瞰でも判別できるよう帽子・髪色・持物で識別する
- UIは白ピル＋黄アクセントで盤面に浮かせる（モックアップ参照）
- サウンド: 白杖の音、連鎖が伸びるほど重なるハーモニー（**親切が演奏になる**）、街の環境音

## 15. 表現の配慮と教育性

- お爺さんは「助けられる存在」ではなく**主体のプレイヤーキャラ**。道を選ぶのは常に彼で、失敗しても辱められない（静かに帰るだけ）
- 点字ブロックの文法は実仕様（視覚障害者誘導用ブロックの整備指針）に準拠 → 遊んだ後に実世界で点字ブロックが読める
- 白杖の音や街の生活音を採用し、視覚障害者団体の監修を推奨
- 色覚多様性: 黄色ブロックは明度と形状（棒／点）でも判別可能に
- 嘘つきお兄さんは「悪人」ではなく**方向音痴の自信家**。善意と効果が完璧に逆なだけで、1回目で爺が学習し、必ずカウンタで無力化できる
- ありがた迷惑は「いらだち」ではなく「攻略対象」として必ず逆利用を1行で書く（§4）——副作用が仕打ちにならない保証

## 16. 成功の定義（検証基準）

- 「あの角だ」と分かる: 実在の自分の街が盤面として認識できる（自分の街感の成立）
- 1ステージ3〜5分（実時間の目安。リトライ起動10秒以内のテンポ）
- 初見死ゼロ: すべてのクセは導入ステージで単独紹介済みであること
- 完全情報の観察: 盤面を見ただけで解き方が読み始められる（静止画盤面の検証基準）
- コンボの気持ちよさ: 親切が連鎖した瞬間に演出・スコア・ハーモニーの3点で報いる

## 18. 技術リスク

- **道路・歩道データの都市差**（最大リスク）: PLATEAUの道路モデルは車道・歩道の幅員情報を持ち、SDKで道路ネットワークを生成できるが、地域により整備度・LODが異なる。→ **最初にやるべきは「あなたの街のデータ検証」**（丸の内コリドーは検証済み・docs/step0-data-verification.md）。フォールバック（疑似歩道生成）を必ず用意。
- 点字ブロックの実データは存在しない → 自動生成＋手編集ツールが本企画の必須成果物。
- メッシュ負荷: 結合・間引き・高さ量子化、影は簡易化。
- 決定論: シミュ層と描画層の分離。v0.3 では時刻・秒の状態変数が存在しないため、シミュは「位置×歩数×ピース状態」の有限集合上の離散遷移のみ——ソルバQAとリプレイ共有の実装は v0.2 想定より大幅に単純。
- PLATEAUデータ利用のクレジット表記（利用規約）。

## 20. 後回し棚（v0.3 で外した案の記録）

すべて案として有効。戻す条件を添えて保存する。

- **する親切（D36）**: お爺さん側の親切イベント。財布拾い＝最寄り交番へ届ける迂回（交番＝お巡りさん＝嘘つきカウンタへの幾何的接続。交番のない盤面は生成器制約で回避）／席を譲る＝回復を打ち切ってコンボを延ばす「元気を払う親烈」。→ 戻す条件: コアの解き心地が固まり、盤面に「する親切」を置く余白が欲しくなったら。
- **ありがた迷惑キャラ（D37）**: ヤンキー（環境阻害・常にいる）×路地ばた会議（環境情報源・接触で噂1つ入手）。聞く会議の角を選ぶ＝逃げ先（＝副作用の設置先。逃げ先でバイクが点字を潰す＝置き自転車技の流用）を選べる。再会で自発的にどく。→ 戻す条件: 阻害系のバリエーションが欲しくなったら。悪役にしない配慮（§15）を引き継ぐ。
- **地割れと乗り物（D38）**: 閉鎖の第3段階「掘削（担送不可・乗り物のみ可）」＋ヒッチハイク升（決まった時刻→待ちN手で顔なじみの車が通り、地割れの向こうの固定降り場まで運ぶ・1回限り）。副作用は乗り越し（降り場固定）。写真テストのため原型は実在の車（夕方の焼き芋トラック／迎えの車／牛乳配達）に差し替える。→ 戻す条件: 閉鎖2段階では単調になったら。時刻・待ち秒は離散表現（D39準拠）で書くこと。
- **土地勘（旧D10/D26）**: ストック型の「自分で判断する」回数。強制イベントへの抵抗チケット。→ 戻す条件: 幾何カウンタだけでは詰みや理不尽が作れない盤面が出てきたら。復活時は判断順レイヤーの再設計がセット。
- **泣いてる子供（旧D22）**: 連れ帰り触発型。「同じ道を2度通る」を作る装置。→ 戻す条件: 技術点の再訪問題を盤面設計だけで作れなくなったら。
- **マッチョ＋弱い工事（旧D14/D27）**: 担送で渡れる橙白バリケード。「遠回りと突破」のコスト比較レバー。→ 戻す条件: 閉鎖が2段階で単調になったら（地割れと合わせて再検討）。
- **回復の多様化（§8）**: 狛犬（お参り回復）／ラジオ体操（常時・1回限り全回復）／バス停ベンチ（回復・待機点）／喫茶店のマスター（強制1手停め＋全回復）。→ 戻す条件: 回復1種で盤面設計が単調になったら。時刻限定（朝のみ等）は廃止済みのため再設計時に持ち込まないこと。
- **アーキタイプB/C/D（旧D17含む）**: 固定キャスト（0手パズル）／石の街（置いたら移動禁止・効果+50%）／ミューテーター（雨・お祭り——ラッシュ時は時刻廃止で削除済み）。→ 戻す条件: 自由配置ステージの在庫が十分に増えた後。
- **音③系（野良猫）**: 機能系統の空席。「猫は動かず、お爺さんが釣られて寄る」静的再設計で復帰可（誘引方向と危険方向の幾何を盤面に固定する）。
- **タクシー運転手**: 強気の任意方向矢印。→ 戻す条件: 嘘つきと被らない役割（中距離の荒い矢印）が必要になったら。
- **メタ進行（旧D12/D19）**: お礼コレクション／リプレイ劇場（決定論があるのでいつでも実装可）／今日の親切（デイリー）／週替わりチャレンジ／称号・街実績／パズル生成コンテスト。→ 戻す条件: 縦スライス完成後。
- **電車と踏切・人波・通学路**: 動くもの・時刻に依存するため廃止（D39/D40）。
