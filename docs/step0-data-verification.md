## 企画への含意

1. **歩道部ポリゴンが実在する**(2,482 面)。D15「道の中央の点字ブロック網=誘導レーン」は
   道路中心線の推測ではなく、**実歩道ポリゴンを縮約/センタリングした線**から生成できる。
   自動生成ツールの入力はこれを第一候補にする。
2. **横断(パスの切れ目)もデータから取れる**: 歩道部ポリゴン網のトポロジから切れ目を抽出し、
   車道交差部(960 面)は交差点の位置合わせに使える。「横断歩道がなく渡れない」地点の
   自動検出(D15 の事故メタファー)は歩道グラフの連結性解析で実装可能。
3. **トゥーン都市は成立**: 建物 LOD2 98.6% + 高さ 100%。LOD1 に落とせば軽量、
   ランドマーク周辺だけ LOD2/3 という MILO 構成が可能。道路も LOD3 があるので
   縁石の立体感まで残せる。
4. 点字ブロック実データは無い(想定どおり)→ 自動生成+手編集ツール仕様は維持。
   ただし生成の基準面が「道路中心線」ではなく「実歩道」にできるのは設計上の有利。
